# 表1 2022版与当前论文版本的功能和技术路线比较

比较基于2022年论文、Windows/macOS原始实验冻结代码`GriddingMachine@53bb0be`与`GriddingMachineDatasets@3926ae3`，以及公开候选提交`11631d6`、`5eac56a`和研究仓库实验冻结提交`8a23b5a`。表中“当前论文版本”只描述已有代码和实验能够支持的行为；未完成工作在“证据或边界”列明确说明。

| 环节 | 2022版 | 当前论文版本 | 证据或边界 |
|---|---|---|---|
| 标准数据文件 | 标准NetCDF打包为`tar.gz` artifact | 标准NetCDF以`.nc`直接分发 | 两个内部压缩样本的暖缓存中位时间在Windows降低48.3%和82.9%，在macOS降低53.6%和69.2%；不外推至全部文件或冷缓存 |
| 数据目录 | 软件包内置`Artifacts.toml`，随软件版本发布 | 外置且具有schema的`Artifacts.yaml`，可独立更新 | 目录更新使用临时文件校验后事务替换；历史目录尚未全部补齐完整性字段 |
| 数据标识 | 标签、SHA-1、SHA-256和一个或多个下载URL映射Julia artifact | 标签映射逻辑`PATH`和URL；新登记或已迁移条目增加`SIZE/SHA256` | 14/1179项具备严格完整性字段，72/1179项具备多URL |
| 下载与落盘 | Julia artifact下载、哈希寻址和解包 | 下载至独立cache；具备`SIZE/SHA256`时核验后移入public | 默认非严格模式兼容历史条目；严格子集和受控故障均未把错误内容落入正式文件 |
| 镜像选择 | 由artifact条目提供下载地址 | 按Windows `ping`结果排序，异常时依次尝试后续URL | `Inf`地址仍保留在尝试队列；校园网24/24次完整性通过，但ping不代表一般下载吞吐率 |
| 目录更新 | 更新目录通常需要发布软件版本 | `update_database!`可独立刷新YAML目录 | 自动回归覆盖合法更新、损坏目录拒绝和上一有效目录保护 |
| 数据读取 | `read_LUT`提供按标签和位置读取 | `read_dataset`统一整场、周期和站点读取，`read_LUT`保留为别名 | 仅适用规定的全球规则经纬网；无坐标插值和单位转换 |
| 模型数据组织 | 主要提供标准化数据及通用读取 | `grid_dict`组织陆地参数，`grid_weather`组织气象驱动 | 真实`gm2`陆面链路与合成气象烟雾已验证；真实ERA5和长期模拟未验证 |
| 数据生产 | 数据源专用脚本与人工贡献流程 | 共享YAML schema描述文件、维度、变量及处理规则，通用流水线生成标准NetCDF | 二维、三维显式维度映射和六类缺失值策略已测试；部分历史YAML仍待迁移 |
| 贡献入口 | 文档与数据源专用代码 | 配置构建器与流水线共享schema，由构建器或模板生成YAML | 已移除遗留`TARBALL`和固定输出路径；当前无独立客户端，不作界面可用性声明 |
| 质量检查 | 数据规范、处理日志和发布前检查 | 自动结构、坐标和数值断言，方向图补充审核及目录完整性检查 | 29个非交互案例在Windows与macOS各连续3轮通过、Ubuntu CI 1轮通过；单人方向审核PASS，不作为多用户可用性证据 |
| 语言接口 | Julia、MATLAB、Octave、Python和R | 新版目录与模型就绪接口集中于Julia | 非Julia接口未在本文重新验证 |

**Table 1 Comparison between the 2022 release and the current manuscript version of GriddingMachine.** Only behavior supported by the frozen code and archived experiments is reported; remaining limitations are stated explicitly.
