# 新贡献者受控流程实验手册（Windows）

## 1. 实验目的

检验一名未参与相关代码开发的组内成员，能否只根据本手册完成“读取输入说明—填写YAML—运行生产流水线—生成本地模拟目录”的受控流程。本实验不访问FTP、Zenodo或GitHub，不上传、覆盖或删除任何网站内容，也不用于推断一般用户完成率。

## 2. 角色和记录原则

- 参与者：至少1名未参与相关代码开发的人。
- 协调者：只负责提供本手册和启动命令，不能替参与者填写YAML。
- 参与者遇到问题时可以请求提示，但每次提示必须记入`participant_record.toml`。
- 失败不能删除重来；先保存错误信息，再修正并记录修正内容。

## 3. 准备用例

协调者在PowerShell执行，其中`P01`可替换为参与者编号：

```powershell
Set-Location 'D:\Emerald\GriddingMachine_Reaserach\论文\experiments\03_01_data'
julia --startup-file=no --project=D:\Emerald\GriddingMachine_paper prepare_contributor_case.jl P01
```

用例位于`D:\Emerald\GriddingMachine_Reaserach\experiment_data\03_01\contributor_flow\P01`。处理前，参与者只编辑其中的`contributor.yaml`；验收后再填写脚本预先生成的`participant_record.toml`。

## 4. 填写YAML

依据下表替换`null`和空数组。字符串保留引号并使用英文符号。

| 字段 | 填写值 |
|---|---|
| `SCHEMA_VERSION` | `1` |
| `FILE.PATTERN` | `"PREFIX_NX_X_MT_VV.nc"` |
| `FILE.PREFIX` | `["SRC"]` |
| `FILE.NX` | `[2]` |
| `FILE.MT` | `["1Y"]` |
| `FILE.VV` | `["V1"]` |
| `FOLDER.ORIGINAL` | `"case-input"` |
| `FOLDER.REPROCESSED` | `"case-output"` |
| `DATA.ABOUT` | `"controlled contributor fixture"` |
| `DATA.DIMENSIONS.source` | `["lat", "lon"]` |
| `DATA.FLIP_LON` | `true` |
| `DATA.GAPFILL` | `"KEEP_AS_IS"` |
| `DATA.LABEL` | `["source"]` |
| `DATA.LIMITS` | `[23, 49]` |
| `DATA.REV_LAT` | `true` |
| `DATA.SCALING` | `"linear"` |
| `DATA.SCALING_FACTOR` | `[2, 1]` |
| `DATA.UNIT` | `"1"` |
| `DATA.VERIFY_ONCE` | `false` |
| `GRIDDINGMACHINE.TAG` | `"CONTRIB"` |

`DATA.CHANGE_LOGS`保持`[]`。保存后不要改动源NetCDF文件。

## 5. 运行和自动验收

参与者执行：

```powershell
Set-Location 'D:\Emerald\GriddingMachine_Reaserach\论文\experiments\03_01_data'
julia --startup-file=no --project=D:\Emerald\GriddingMachine_paper validate_contributor_case.jl P01
```

显示`Contributor case PASS`表示：YAML通过schema；源维度、纬度、经度、缩放和范围处理与固定金标准一致；输出NetCDF生成；本地模拟`Artifacts.yaml`的`SIZE/SHA256`正确。`example.invalid`只是模拟URL，不会被访问。

## 6. 人工记录

参与者编辑用例目录中已生成的`participant_record.toml`，把默认的未完成状态更新为实际结果。例如无提示、无失败且指南清楚时填写：

```toml
participant = "P01"
completed_without_help = true
verbal_help_count = 0
failed_attempt_count = 0
failed_step = ""
error_summary = ""
guide_was_clear = true
notes = ""
```

如请求过提示，将`completed_without_help`设为`false`并准确填写次数和问题。协调者核对`automatic_result.toml`为PASS后，才可在论文中报告该案例完成。

## 7. 论文允许的结论

一名参与者完成时只能写：“一名未参与相关代码开发的参与者依据冻结指南完成受控配置、生产和模拟目录登记。”不能写“多数用户”“普遍易用”或虚构更多参与者。
