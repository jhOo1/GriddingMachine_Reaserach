# V01/V02 Windows人工方向审核流程

## 1. 审核目标

确认软件生成的方向图能让实验者识别正确的经纬方向，并能拒绝故意南北翻转的图。V01为正确图，应接受；V02为故意错误图，应拒绝。本流程评价软件审核步骤是否可操作，不评价真实数据的科学质量。

姜皓可以作为第一位实验者。如果姜皓没有参与相关代码开发，可计为一名“未参与开发的审核者”；正式论文若要写“两名独立审核者”，仍需另一名组员不查看姜皓的答案，使用不同审核编号独立运行一次。

## 2. 图像判据

正确图必须同时满足：横轴为Longitude、从左侧-180°增加到右侧180°；纵轴为Latitude、从底部-90°增加到顶部90°；左上角是最亮的矩形块，右上角是次亮块；左下角是最暗块，右下角是次暗块；背景颜色从南向北逐渐增加。

只要任一条件不满足就拒绝。不要根据终端提示机械输入答案，必须先打开图像检查。

## 3. 操作步骤

1. 打开PowerShell。
2. 执行：

   ```powershell
   Set-Location 'D:\Emerald\GriddingMachine_Reaserach\论文\experiments\03_01_data'
   julia --startup-file=no --project=D:\Emerald\GriddingMachine_paper run_manual_orientation_audit.jl
   ```

3. 输入审核编号。姜皓第一次可输入`HJ01`；第二位审核者应使用不同编号，例如`R02`。
4. 等待V01生成完成。终端会显示`orientation.png`的完整路径，但此时正在等待输入。
5. 用资源管理器打开该PNG，按第2节逐项检查。V01全部正确时回到PowerShell输入`y`并回车；不正确则输入`n`。
6. 等待V02生成完成，再打开V02目录中的PNG。该图应当南北颠倒，必须输入`n`拒绝；如果看不出错误，不要输入`y`，应记录为失败。
7. 终端显示`PASS`才表示本次审核成功。结果保存在对应审核编号目录的`audit_record.toml`，两张图和fixture同时保留。

## 4. 结果解释

- V01输入`y`且V02输入`n`：本次审核通过。
- 其他任意组合：审核失败，保留记录并说明看错、图未生成、路径打不开或软件报错的具体步骤。
- 一个人通过只能报告“一名实验者完成流程”；两名不同审核者各自通过后，才能报告“两名独立审核者通过”。
