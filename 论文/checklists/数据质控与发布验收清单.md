# GriddingMachine 数据质控与发布验收清单

> 用途：论文实验版本发布前的门禁清单。任何一项标记为“阻塞”的检查未通过时，不得更新正式 `Artifacts.yaml`，也不得将该数据计入论文的已发布数据统计。

## 3. 事务式发布顺序

1. 在隔离环境运行 YAML schema 和生产流水线。
2. 对输出执行结构、坐标、数值、缺失值和元数据自动检查。
3. 完成人工空间方向复核并记录审核人，不用它代替自动检查。
4. 计算本地文件字节数和 SHA-256，冻结发布记录。
5. 上传公共镜像和可选机构镜像；不关闭 TLS 证书验证。
6. 从每个远端重新核对对象大小和内容哈希。
7. 在临时目录更新目录副本，检查标签冲突、镜像一致性和 schema。
8. 发布新目录版本并保留上一版本；失败时整体回滚。
9. 在 Linux、macOS 和 Windows 上执行“刷新目录—下载—校验—读取”冒烟测试。
10. 所有门禁通过后，才把该标签计为正式发布并用于论文实验。
